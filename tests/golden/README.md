# Golden-chart suite — provenance

`fixtures.json` holds the expected values for `tests/unit/golden-astronomy.test.ts`.
They are produced by `scripts/golden/generate.ts` from the **independent reference
pipeline** in `scripts/golden/reference.ts`. That pipeline imports nothing from
`server/`, so the engine under test never supplies its own expected values.

Regenerate with `npx tsx scripts/golden/generate.ts`, and review the diff. A change
to the fixtures is a change to the truth the engine is checked against.

## Reference methodology

| Quantity | Reference source |
|---|---|
| Birth instant | Hand-written `expectedOffset` per case from IANA tz rules (`scripts/golden/cases.ts`); local time minus that offset. |
| Planet longitudes | `astronomy-engine` (D. Cross; VSOP87 planets, ELP/MPP02-based Moon), apparent geocentric, rotated to the **J2000 mean ecliptic**. |
| Sidereal frame | λ_sidereal = λ_J2000 − K, with K = 23°51'25.53" (the Lahiri ayanamsa at J2000.0). K is cross-checked in the suite: it puts Spica at ~180° sidereal, which is the Chitrapaksha definition of Lahiri. |
| Mean node | Meeus, *Astronomical Algorithms* (2nd ed.) eq. 47.7, minus the mean Lahiri ayanamsa of date. |
| Ascendant / MC | Spherical-astronomy formulas from IAU-1982 GMST and Laskar mean obliquity, minus the mean Lahiri ayanamsa. |
| Retrograde | Sign of a ±12 h central difference of the reference longitude. Bodies moving slower than 0.02°/day (stationary) are not asserted. |
| D9 / D10 | Rules written from their textual definitions: D9 movable/fixed/dual from the sign/9th/5th; D10 odd/even from the sign/9th. This differs from the engine's formulation. |
| Vimshottari | Rule written independently: birth Mahadasha placed at its virtual start, 365.25-day years. |

Boundary cases (`b-*`) are generated by bisecting the reference ephemeris for a Moon
nakshatra, sign or pada crossing, or an Ascendant sign change, then stepping 25 min
(Moon) or 2 min (Ascendant) to either side. Retrograde cases (`r-*`) are dates
inside well-known retrograde loops; their truth still comes from the reference.

## Tolerances

The worst engine/reference gap observed over all cases is ≈13″, for the Ascendant;
planets are ≤11″. Longitude tolerance is **30″**. Discrete facts (sign, house,
nakshatra, pada, D9, D10, Ascendant sign) are asserted only when the reference
longitude is more than **0.03°** from a division edge. Mahadasha dates are allowed
the date error implied by the Moon tolerance (≈2 days per 20-year period) plus 1 h.

## Jyotish rule tests

`tests/unit/golden-jyotish-rules.test.ts` is separate. It holds synthetic longitudes
with hand-derived expectations (vargas, Vimshottari/Yogini, partial Shadbala,
selected yogas and doshas), so a rule change cannot hide behind astronomy.
